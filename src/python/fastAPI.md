# FastAPI

## 导入

| 函数/属性/其他              | 说明                              |
|---------------------------|-----------------------------------|
| `FastAPI`                  | FastAPI 应用的主要类              |
| `APIRouter`                | 用于组织路由的类                  |
| `Depends`                  | 依赖注入机制                      |
| `Path`                     | 路径参数验证器                    |
| `Query`                    | 查询参数验证器                    |
| `Body`                     | 请求体参数验证器                  |
| `Header`                   | 请求头参数验证器                  |
| `Cookie`                   | Cookie 参数验证器                 |
| `Form`                     | 表单参数验证器                    |
| `File`                     | 文件上传参数验证器                |
| `UploadFile`               | 上传文件类型                      |
| `JSONResponse`             | 返回 JSON 响应                    |
| `RedirectResponse`         | 重定向响应                        |
| `Response`                 | 响应类，支持各种类型的响应        |
| `status`                   | HTTP 状态码常量                   |
| `HTTPException`            | HTTP 异常类                        |
| `BackgroundTasks`          | 背景任务类                        |
| `Request`                  | 请求对象                          |
| `WebSocket`                | WebSocket 连接对象                |
| `WebSocketDisconnect`      | WebSocket 断开连接异常            |
| `ResponseModel`            | 响应模型类                        |
| `JSON`                     | JSON 类型响应                     |
| `HTMLResponse`             | HTML 类型响应                     |
| `StreamingResponse`        | 流式响应                          |
| `Request`                  | 请求数据类                        |
| `Security`                 | 安全机制相关工具                  |
| `OAuth2PasswordBearer`     | OAuth2 密码 bearer 认证           |
| `OAuth2PasswordRequestForm`| OAuth2 密码请求表单               |
| `OAuth2`                   | OAuth2 认证相关                   |
