# 字典

以下是 Python 字典（dict）相关的一些常用函数和方法：

| 函数/方法名称 | 说明 |
| --- | --- |
| `dict()` | 创建一个新的字典对象。 |
| `len()` | 返回字典中键值对的数量。 |
| `clear()` | 移除字典中的所有项。 |
| `copy()` | 返回字典的浅复制。 |
| `fromkeys()` | 创建一个新字典，以序列中的元素作为键，并设置所有键的值为指定值。 |
| `get()` | 返回指定键的值，如果键不在字典中，则返回默认值。 |
| `items()` | 返回字典中的所有键值对作为一个视图对象。 |
| `keys()` | 返回字典中的所有键作为一个视图对象。 |
| `pop()` | 移除并返回指定键的值，如果键不存在，则返回默认值。 |
| `popitem()` | 移除并返回字典中的最后一个键值对。 |
| `setdefault()` | 返回指定键的值，如果键不在字典中，则插入键并设置其值为默认值。 |
| `update()` | 使用指定的键值对更新字典。 |
| `values()` | 返回字典中的所有值作为一个视图对象。 |
